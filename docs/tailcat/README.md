# Gallery+ Tailcat receiver

This static page is opened from the Gallery+ QR code. It creates a browser Tailcat receiver address, sends that address back to the vehicle app through the vehicle Tailcat control address in the `car` query parameter, then receives the selected Saved file.

Expected URL shape:

```text
https://lamer0712.github.io/PolestarDashcam/tailcat/?file=name.mp4&car=tc...
```
